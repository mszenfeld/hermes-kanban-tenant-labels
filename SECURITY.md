# Security policy

## Reporting a vulnerability

Open the repository's Security tab → Report a vulnerability to create a private
security advisory. Do not open a public issue.

Include the plugin version and Hermes Desktop version, the impact, and the steps
to reproduce.

## Supported versions

Only the latest release is supported.

## Scope

The plugin runs in the Hermes Desktop renderer with the app's permissions.
Security problems include a tenant name or stored pin that injects markup or
runs code, or data read or sent beyond what the README describes in
[Permissions & privacy](README.md#permissions--privacy).
